# Keyboard shortcuts

A small set of shortcuts for keyboard-heavy workflows. The same list is available in-app from the account menu → **Keyboard shortcuts…**.

| Keys                | What it does                                                         |
| ------------------- | -------------------------------------------------------------------- |
| `⌘ K` or `/`        | Focus the Registry search bar                                        |
| `Esc`               | Close the open dialog or drawer                                      |
| `←` / `→`           | Move between Registry / Installed tabs (when a tab strip is focused) |
| `Enter` or `Space`  | Open the focused skill card's detail drawer                          |
| `Tab` / `Shift+Tab` | Move focus through cards and controls                                |

## Notes

- `⌘ K` and `/` are equivalent. Use whichever is closer to your hand. The shortcut also works while a card or button is focused — it doesn't fire while you're typing in another input.
- Tab order across the grid follows visual reading order (left-to-right, top-to-bottom).
- The drawer traps focus while open and returns focus to the originating card on close.

## Future

The shortcut overlay is the discoverability surface for this list — when we add more, they show up there first. If you have ideas for shortcuts that would help your flow, open an issue.
