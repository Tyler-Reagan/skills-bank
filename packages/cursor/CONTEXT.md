# Cursor

Cursor reads the Store natively. Skills Bank does not Project skills into `~/.cursor/skills`. There is no install-to-Cursor toggle. Every Store skill is visible to Cursor. A hand-made folder that lives only under `~/.cursor/skills/<name>/` stays there and stays out of the Store.

This context will own Cursor-only objects when the cursor package is built. Those terms are not defined here yet.
